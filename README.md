# Portafolio Web - Maximiliano Opazo

## Descripción

Este proyecto consiste en el desarrollo de un portafolio web personal, creado para presentar mi perfil como estudiante de Programación, mis habilidades, estudios y proyectos realizados.

El sitio cuenta con un diseño inspirado en una estética cyberpunk, utilizando colores oscuros, detalles de iluminación y tonos morados y naranjas. También está adaptado para distintos tamaños de pantalla, como computadores, tablets y celulares.

## Tecnologías utilizadas

* **HTML5:** estructura y contenido de la página.
* **CSS3:** diseño visual, animaciones, efectos y adaptación a distintos dispositivos.
* **JavaScript:** interactividad y funcionamiento del menú de navegación.
* **Bootstrap 5:** framework utilizado como apoyo para el desarrollo.
* **Git:** control de versiones y seguimiento de los cambios.
* **GitHub:** almacenamiento del repositorio y publicación del proyecto mediante GitHub Pages.

## Secciones del portafolio

* **Inicio:** presentación personal.
* **Sobre mí:** información sobre mi perfil, intereses y objetivos.
* **Proyectos:** muestra de proyectos desarrollados y en proceso.
* **Habilidades:** lenguajes de programación, herramientas y conocimientos.
* **Estudios:** formación académica y complementaria.
* **Contacto:** medios para encontrarme y comunicarse conmigo.

## Visualización del proyecto

El portafolio puede visualizarse desde GitHub Pages:

**Enlace:** (https://makopz.github.io/Portafolio-Maximiliano_Opazo/)

También es posible ejecutar el proyecto localmente:

1. Clonar o descargar este repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Abrir el archivo `index.html` en un navegador o utilizar la extensión Live Server.

## Uso de Inteligencia Artificial

Durante el desarrollo de este proyecto se utilizó **ChatGPT, de OpenAI**, como herramienta de apoyo para resolver dudas, proponer ideas de diseño, organizar el código y comprender el funcionamiento de algunas características.

La inteligencia artificial se utilizó principalmente para:

* Proponer estructuras HTML para las distintas secciones.
* Mejorar los estilos CSS y la presentación visual.
* Apoyar la adaptación del diseño a dispositivos móviles.
* Desarrollar y revisar la funcionalidad del menú de navegación.
* Resolver dudas y detectar posibles errores en el código.
* Mejorar la organización y presentación de los contenidos del portafolio.

Las sugerencias proporcionadas fueron revisadas y adaptadas durante el desarrollo del proyecto.
